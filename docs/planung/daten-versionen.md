# Bestätigte Planungsrunde: Daten, Versionen und Zusammenarbeit

Datum: 9. Oktober 2026. Status: bestätigt. Antwort „aaaaaaaaaa“ als 1A bis 10A übernommen.

1. **A bestätigt:** Eine unabhängig vorbereitete Show wird als eigene Veranstaltungskopie aufgenommen. Spätere Änderungen der Vorlage werden bewusst übernommen, nicht automatisch.
2. **A bestätigt:** Änderungen gemeinsam verwendeter Szenenvorlagen werden angezeigt; Übernahme ist je Verwendung bewusst auswählbar.
3. **A bestätigt:** Verwendete Medien können nicht gelöscht werden. Das System zeigt die betroffenen Verwendungen.
4. **A bestätigt:** Shows und Szenen werden zunächst in einen wiederherstellbaren Papierkorb verschoben. Eine Papierkorbaktion hebt Verwendungs-/Live-Schutzregeln nicht auf. Aufbewahrungsdauer und endgültige Löschung bleiben zu konkretisieren.
5. **A bestätigt:** Wenn zwei Personen dasselbe gemeinsam bearbeitbare Textfeld ändern, wird ein Konflikt angezeigt und beide Fassungen bleiben zur Auswahl erhalten. Die bestehende exklusive Szenenbearbeitung bleibt unverändert.
6. **A bestätigt:** Bei Verbindungsverlust werden ungespeicherte Änderungen lokal als Wiederherstellungsentwurf gehalten und später abgeglichen. Ein lokaler Entwurf ist keine bestätigte Serverspeicherung. Er ersetzt keine Offline-Livefreigabe und umgeht weder Rechteprüfung noch Szenensperren.
7. **A bestätigt:** Die Änderungshistorie besteht aus automatischem Verlauf und benennbaren Ständen, beispielsweise „Generalprobe“.
8. **A bestätigt:** Ein älterer Stand wird bei Wiederherstellung als neue aktuelle Fassung übernommen. Der bisherige Verlauf bleibt erhalten; eine Wiederherstellung aktiviert nicht automatisch den Livebestand.
9. **A bestätigt:** Beim Vergleich werden geänderte Inhalte hervorgehoben; für Szenen gibt es zusätzlich eine Bildvorschau.
10. **A bestätigt:** Inhaltsänderungen während einer laufenden Veranstaltung werden als Entwurf gespeichert. Übernahme in den Livebestand erfolgt ausschließlich durch ausdrückliche berechtigte Aktion.

Siehe D008 im [Entscheidungsprotokoll](entscheidungen.md). Diese Regeln sind Zielanforderungen, keine bereits implementierte Software.
